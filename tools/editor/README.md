# Pixelica Editor 0.1

Pixelica 2D 렌더러로 장면을 편집하고 실행하는 데스크톱 도구입니다.
프로젝트 데이터, 렌더러 어댑터, 편집 UI를 분리하고 위치·회전·크기를 3축으로 저장합니다.
현재 편집 화면과 실행 백엔드는 2D입니다.

## 실행

Python 3.10 이상과 Tk, Pillow가 필요합니다. 첫 실행의 네이티브 브리지 빌드에는
CMake 3.21 이상과 C 컴파일러가 필요합니다. Windows는 Visual Studio 2022의 C++ 개발 도구를 사용합니다.

```powershell
python -m pip install -r tools/editor/requirements.txt
python tools/editor/launch_editor.py
```

Windows에서는 `Pixelica Editor.cmd`를 더블 클릭해도 됩니다.
첫 실행은 브리지를 `build-editor/`에 만들며, 이후에는 생성된 라이브러리를 재사용합니다.
소스를 바꿨다면 `python tools/editor/launch_editor.py --build`로 다시 빌드합니다.

## 기본 작업

1. 샘플 장면에서 오브젝트를 선택하고 캔버스에서 드래그합니다.
2. 속성 창에서 위치·회전·크기·색·투명도·레이어 등을 변경합니다. 적용 버튼이나 Enter로 반영합니다.
3. 프로젝트를 저장합니다. 이미지 가져오기는 프로젝트 폴더의 에셋으로 복사합니다.
4. 실행을 누르고 게임 화면을 클릭하면 WASD/방향키로 조작 가능한 오브젝트를 움직입니다.
5. 정지하면 실행 중 움직인 데이터가 버려지고 편집 배치로 돌아옵니다.

샘플 플레이어는 중력과 충돌이 켜져 있습니다. A/D·좌우 방향키로 이동하고 Space/W/위쪽
방향키로 점프합니다. 오브젝트의 충돌 설정에서 고정 벽/바닥·플레이어·트리거를 빠르게 설정하고
충돌 영역 표시를 보며 맞추세요. [충돌·중력·점프 안내](../../docs/collision2d.md)

저장·실행·선택 변경 시 아직 적용하지 않은 입력도 반영합니다. 잘못된 입력이 있으면 해당 동작을
멈추고 오류를 표시합니다. 이미지 선택은 PNG/JPEG/BMP/PPM을 지원합니다.
다른 폴더로 저장하면 현재 참조 이미지를 함께 복사하고 실행 취소 기록은 초기화합니다.

`Ctrl+S` 저장, `Ctrl+Z/Y` 실행 취소/다시 실행, `Ctrl+D` 복제,
`F5` 실행/일시정지, `Esc` 정지를 지원합니다.
선택한 오브젝트는 방향키로 1픽셀씩 이동하며 격자 맞춤을 켜면 16픽셀씩 이동합니다.
마우스 휠은 확대·축소, 가운데 버튼 드래그는 화면 이동입니다.

상세 구조·데이터 수명·제한은 [개발 문서](../../docs/editor.md)를 참고하세요.

## 검증

```powershell
python tools/editor/launch_editor.py --test
```

프로젝트/저장 검사는 GUI 없이 실행할 수 있습니다. UI 검사는 실제 Tk 디스플레이가 필요합니다.
게임 EXE 내보내기, 3D 뷰포트, 임의 스크립트 실행은 이 버전에 포함되지 않습니다.
