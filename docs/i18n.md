# Pixelica 다국어: UTF-8 번역표와 비트맵 폰트

`Pixelica::common`에 기본 포함됩니다. 언어별 번역표를 등록하고 `pixelica_i18n_set_locale()`로
언어를 바꾸면 됩니다. 번역이 없으면 기본 언어, 그것도 없으면 키 자체를 반환합니다.
UI 위젯에는 `pixelica_i18n_get_n()`으로 문자열과 바이트 길이를 함께 설정하세요.
한글은 내장 `pixelica_font_korean()`을 UI·2D 텍스트에 연결해 바로 표시할 수 있습니다.
별도 BDF에서 게임에 필요한 글자만 추출하는 방식도 유지합니다.
C 소스는 UTF-8로 저장하고, MSVC 소비자에는 `target_compile_options(my_game PRIVATE /utf-8)`을 설정하세요.

Two small, independent pieces:

- `pixelica/i18n.h` (`src/game/i18n.c`): caller-owned, no-heap string catalogs
  with a current locale and a fallback.
- `tools/pixelica_font.py`: turns a Unicode **BDF** font plus your game strings
  into a C header with only the glyphs you use, as a `PIXELICA_UI_Font`.

Out of scope: printf-style formatting, plurals, RTL, complex shaping
(Arabic/Indic ligatures, combining-mark layout), gettext/`.po` parsing and
TTF/OTF loading. Each Unicode codepoint is one fixed-size bitmap cell.

## Catalogs

```c
#include "pixelica/i18n.h"

static const PIXELICA_I18N_Entry en_entries[] = {
    {"menu.start", "Start"}, {"menu.quit", "Quit"}};
static const PIXELICA_I18N_Entry ko_entries[] = {
    {"menu.start", "시작"}, {"menu.quit", "종료"}};
static const PIXELICA_I18N_Entry ja_entries[] = {
    {"menu.start", "開始"}};                      /* "menu.quit" falls back to en */

static const PIXELICA_I18N_Locale locales[] = {
    {"en", en_entries, 2}, {"ko", ko_entries, 2}, {"ja", ja_entries, 1}};

PIXELICA_I18N_Catalog cat;
pixelica_i18n_init(&cat, locales, 3, "en");      /* default = current = fallback */
pixelica_i18n_set_locale(&cat, "ko");
const char *s = pixelica_i18n_get(&cat, "menu.start");
```

Lookup order: current locale, then the default (fallback) locale, then the key
itself. A missing key therefore shows up visibly in the UI instead of crashing.
`pixelica_i18n_get_n()` also returns the byte length.

Rules enforced by `pixelica_i18n_init()`:

| Check | Status |
| --- | --- |
| NULL catalog/table/name/key/text, bad locale name characters, empty key, invalid UTF-8, duplicate locale name, duplicate key within a locale, entries NULL with count > 0 | `PIXELICA_ERR_INVALID_ARG` |
| more than 16 locales, 1024 entries per locale, or a name > 32, key > 128, text > 4096 bytes | `PIXELICA_ERR_CAPACITY` |
| default locale is not in the table | `PIXELICA_ERR_NOT_FOUND` |

Locale names are `[A-Za-z0-9_-]`, case-sensitive. Strings are strict UTF-8
(no overlongs, surrogates, > U+10FFFF); text may be empty. Entries need not be
sorted; lookup is linear.

`pixelica_i18n_set_locale()` returns `NOT_FOUND` for an unknown locale and
`INVALID_ARG` for NULL/malformed input; in both cases the selection is
unchanged.

### Lifetime and re-init

- The catalog **borrows** the locale table, entry arrays and every string. Keep
  them alive and unmodified while the catalog is in use (static `const` data is
  ideal). Returned strings point into them (or are your own key), so they stay
  valid across `set_locale`.
- `pixelica_i18n_init()` may be called again on the same catalog. It validates
  everything first and writes the catalog only on success: a failed re-init
  keeps the old catalog and selection; a successful one replaces it and resets
  current/fallback to the new default. Re-fetch any cached strings afterwards.
- Single-threaded; no globals.

## Updating UI text on a locale switch

`PIXELICA_UI_Widget.text` is borrowed and not copied, so a switch only takes
effect once you re-assign the widgets:

```c
typedef struct { uint32_t widget; const char *key; } Label;
static const Label labels[] = {{ID_START, "menu.start"}, {ID_QUIT, "menu.quit"}};

static void apply_locale(PIXELICA_I18N_Catalog *cat, PIXELICA_UI_Widget *w, size_t n)
{
    for (size_t i = 0; i < n; ++i)
        for (size_t j = 0; j < sizeof labels / sizeof labels[0]; ++j)
            if (w[i].id == labels[j].widget)
                w[i].text = pixelica_i18n_get_n(cat, labels[j].key, &w[i].text_bytes);
}
/* if (pixelica_i18n_set_locale(&cat, "ko") == PIXELICA_OK) apply_locale(...); */
```

Widgets may be edited between UI calls, so no `pixelica_ui_set_widgets()` is
needed. Widget geometry is yours: Korean/Japanese text is often wider or
narrower than English, so size rects for the longest translation.

## Fonts

1. **For a custom font, supply your own BDF.** Pick a
   Unicode BDF covering the scripts you ship (ASCII, Hangul, kana/kanji) whose
   license permits embedding glyph bitmaps in your game, and keep its license
   notice with your project. The generated header is derived from that font.
2. Put every game string in a UTF-8 text file (a leading BOM is ignored;
   newlines are skipped; other control characters, including tabs, are errors).
   Include strings that appear in all locales, e.g. concatenate your
   translation sources.
3. Generate the header:

```sh
python tools/pixelica_font.py --bdf fonts/my_font.bdf \
    --text assets/strings.txt --name game_font --output src/game_font.h
```

Options: `--text` may repeat; `--include-ascii` adds U+0020..U+007E for dynamic
text such as numbers; `--allow-missing` skips codepoints the BDF lacks (they
then draw the UI's missing-glyph box) instead of failing; `--cell WxH`,
`--ascent N`, `--left N` override the fixed cell.

Use it:

```c
#include "game_font.h"
PIXELICA_UI_Theme theme = pixelica_ui_theme_default();
theme.font = game_font_font(1);       /* scale 1..4 */
```

Cell model: width 1..16, height 1..32, rows packed with bit31 = left pixel.
By default the cell is the BDF `FONTBOUNDINGBOX`: the baseline row (ascent) is
`bbox height + bbox y offset`, and the cell's left edge is the bbox x offset.
Each glyph's `BBX w h x y` places its bitmap relative to that baseline and
origin, so descenders and side bearings land correctly. A set pixel that falls
outside the cell is an error (adjust `--cell/--ascent/--left` or choose a
smaller font). Output is deterministic (sorted codepoints, no timestamps) and
written atomically; on any error an existing output file is left untouched.

The converter is deliberately not a full BDF implementation. It rejects, with
a message: wrong `STARTFONT`, antialiased/multi-bit fonts, `METRICSSET` other
than 0, `SWIDTH1`/`DWIDTH1`/`VVECTOR`, unknown keywords, duplicate `ENCODING`,
`CHARS` mismatches, malformed or oversize bitmap rows, non-zero padding bits,
glyph boxes over 128, files over 16 MiB, NUL bytes, and trailing data. Glyphs
with `ENCODING -1` are ignored.

## 한국어 가이드 (Korean guide)

번역 테이블 사용법:

1. 언어마다 `PIXELICA_I18N_Entry` 배열(`{"키", "UTF-8 문장"}`)을 만들고,
   `PIXELICA_I18N_Locale`에 `"en"`, `"ko"`, `"ja"` 같은 이름과 함께 묶습니다.
2. `pixelica_i18n_init(&cat, locales, 개수, "en")`으로 기본 언어(= 대체 언어)를
   지정합니다. 테이블과 문자열은 복사되지 않으므로 계속 살아 있어야 합니다.
3. `pixelica_i18n_set_locale(&cat, "ko")`로 언어를 바꿉니다. 없는 언어면
   `PIXELICA_ERR_NOT_FOUND`를 반환하고 선택은 그대로입니다.
4. `pixelica_i18n_get_n(&cat, "menu.start", &bytes)` 결과를 UI 위젯의
   `text`/`text_bytes`에 넣습니다. 언어를 바꾼 뒤에는 모든 위젯의 `text`와
   `text_bytes`를 다시 설정해야 화면이 바뀝니다. 번역이 없는 키는 기본 언어
   문장, 그것도 없으면 키 문자열이 그대로 표시됩니다.

글꼴 생성: 직접 라이선스를 확인한 유니코드 BDF 글꼴을 준비하고, 모든 번역 문장을 모은 UTF-8 텍스트
파일과 함께 `tools/pixelica_font.py`를 실행하면 사용된 글자(한글 포함)만 담긴
헤더가 만들어집니다. 글꼴에 없는 글자가 있으면 기본적으로 오류로 중단됩니다.
오른쪽에서 왼쪽으로 쓰는 문자(RTL), 복잡한 글자 조합(shaping), TTF 로딩은
지원하지 않습니다.

## API and path list

Headers/sources:

- `include/pixelica/i18n.h`, `src/game/i18n.c`
- `tests/test_i18n.c`, `tools/pixelica_font.py`, `tools/tests/test_pixelica_font.py`
- `docs/i18n.md` (this file)

C API (`pixelica/i18n.h`):

- Limits: `PIXELICA_I18N_MAX_LOCALES` (16), `_MAX_ENTRIES` (1024 per locale),
  `_MAX_LOCALE_BYTES` (32), `_MAX_KEY_BYTES` (128), `_MAX_TEXT_BYTES` (4096)
- Types: `PIXELICA_I18N_Entry`, `PIXELICA_I18N_Locale`, `PIXELICA_I18N_Catalog`
- `pixelica_i18n_init`, `pixelica_i18n_set_locale`, `pixelica_i18n_locale`,
  `pixelica_i18n_get`, `pixelica_i18n_get_n`

Generated by `pixelica_font.py --name N`: `N_GLYPH_COUNT/WIDTH/HEIGHT` macros
(upper-case), `N_glyph` (a `PIXELICA_UI_GlyphFn`), `N_font(scale)`.

Python API: `parse_bdf`, `convert`, `write_atomic`, `main`, `FontError`.

## 공통 폰트와 2D UTF-8 (2026-10-16)

`pixelica/font.h`의 `PIXELICA_Font`는 UI와 2D가 공유하는 고정 셀 콜백입니다.
기존 `PIXELICA_UI_Font`, `PIXELICA_UI_GlyphFn`은 공통 타입의 별칭으로 유지합니다.
기존 `pixelica2d_draw_text()`의 바이트 폰트 동작은 유지하며, 다국어에는 새 함수를 사용하세요.

```c
#include "pixelica/font.h"
#include "pixelica/renderer2d.h"
#include "pixelica/ui.h"

PIXELICA_Font font = pixelica_font_korean(1); /* 16x16, scale 1..4 */
const char *text = "한글 시작 / 日本語";
size_t missing;
uint32_t first_missing;
PIXELICA_Status coverage = pixelica_font_check_text(
    &font, text, strlen(text), &missing, &first_missing);
/* coverage == OK: 모두 있음; NOT_FOUND: 누락 횟수와 첫 코드포인트 확인.
   INVALID_ARG: 잘못된 폰트 또는 UTF-8; 출력 인자는 변경하지 않음. */
pixelica2d_draw_text_utf8(&ctx, &font, text, strlen(text), 8, 8, 0xffff, 255);
ui.theme.font = font;
```

위 코드는 연결 조각입니다. `ctx`와 `ui`는 먼저 초기화하고 `<string.h>`를 포함합니다.
생성한 기존 BDF 폰트도 동일하게 두 경로에 전달할 수 있습니다.

- UTF-8은 엄격하게 검사합니다. 잘린 시퀀스·overlong·surrogate 등은 2D 그리기 전에 거부하며
  픽셀·깊이·통계는 바꾸지 않습니다. opacity=0이어도 검사합니다.
- 누락 글자는 한 셀의 테두리 상자로 표시합니다. `pixelica_font_check_text()`로 릴리스 전에
  모든 번역 문자열과 동적 사용자 입력 범위를 검사하세요. 검사는 콜백이 false로 보고한 글자에
  기반합니다. 자체적으로 `?`로 대체하고 true를 반환하는 폰트는 누락을 식별할 수 없습니다.
- 셀 간격은 `(width+1)*scale`, 줄 간격은 `(height+1)*scale`입니다. 개행은 글리프 검사에서 제외합니다.
  좌표·클립·색·opacity가 적용되고 카메라·깊이는 무시합니다. 2D 문자열은 최대 65,536바이트이며 UI 위젯 문자열은 4,096바이트입니다.
- 콜백은 순수하고 결정적이어야 하며 폰트·문자열·타깃을 수정하면 안 됩니다. 데이터는 빌려 쓰므로
  호출 동안 유효해야 하고 렌더 타깃과 겹치면 안 됩니다.

### 내장 한글 폰트

`pixelica_font_korean(scale)`은 GalmuriMono11 2.404의 16×16 비트맵을 제공합니다.
완성형 한글 11,172자, ASCII, 가나 및 일부 한자·그리스·키릴 문자 등 총 20,324자를 포함합니다.
모든 Unicode를 지원하는 것은 아닙니다. 이모지·일부 간체 한자는 누락될 수 있습니다.
조합형 한글 입력은 NFC 완성형으로 정규화한 뒤 전달하세요. 엔진은 정규화·조합 배치·RTL·shaping을
수행하지 않습니다. TTF/OTF 런타임 로딩도 추가하지 않았습니다.

기존 `pixelica_ui_font_default()`의 작은 영문 폰트와 UI 레이아웃은 유지합니다.
한글을 쓰는 화면에서는 위처럼 명시적으로 내장 폰트를 지정하고 16픽셀 셀에 맞게 공간을 확보하세요.
내장 폰트 데이터는 common 정적 라이브러리의 별도 오브젝트이므로 호출하지 않는 게임에는 링크되지 않습니다.
비트맵·코드포인트 테이블은 약 715 KiB이며, 임베디드에서 용량을 줄이려면 기존 BDF 서브셋 변환기를 사용하세요.

원본·고정 커밋·체크섬은 `assets/fonts/galmuri/`에 있으며
`python3 tools/generate_builtin_font.py`로 테이블을 재생성합니다. 원본 BDF의 마지막 미인코딩
.notdef로 인한 CHARS 불일치는 고정 원본에만 메모리에서 보정하며 일반 BDF 파서는 엄격하게 유지합니다.
Galmuri 데이터는 **OFL-1.1**이며 엔진 코드 라이선스와 별개입니다. SDK 설치 시
`share/Pixelica/licenses/GalmuriMono11/`에 고지·라이선스를 포함합니다. 해당 데이터를 쓰는 게임에도
고지·라이선스를 동봉하세요.

### 데모와 검증

2D를 켠 HEADLESS 빌드에서 실행합니다. 첫 인자를 생략하면 파일 없이 검증합니다.

```sh
cmake --build build-water --target hello_unicode
./build-water/hello_unicode unicode.ppm
ctest --test-dir build-water -R 'test_font|test_renderer2d|test_ui_render|smoke_hello_unicode|font_tool_unittest' --output-on-failure
```

`hello_unicode`은 한국어·일본어·번체 중국어·영문·그리스·키릴 문자열의 글리프 누락 여부와
UI/2D 전체 픽셀 일치를 검사합니다. `test_font`는 완성형 한글 전체 범위와 누락·잘못된 UTF-8을,
2D 테스트는 4바이트 코드포인트·확대·클리핑·쓰기 전 오류 거부를 검사합니다.
