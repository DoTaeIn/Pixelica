## 기능별 네이티브 예제

| 예제 | 확인할 기능 | 실행 방식 |
| --- | --- | --- |
| `hello_lifecycle` | 체크포인트 저장·종료·재실행 복원 | HEADLESS 검증 |
| `hello_lighting` | 노멀을 사용하는 기본 조명 | HEADLESS 또는 SDL3 창 |
| `hello_pixel_light` | 창문빛 패치·접촉 그림자·선택적 발광 | HEADLESS 캡처·검증 |
| `hello_water` | 잔잔한 물의 평형·파도 위 몸체의 부력 | HEADLESS PPM 캡처·검증 |
