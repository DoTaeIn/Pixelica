# Authoring Guide

## 문서 추가

`website/docs/`에 Markdown 또는 MDX를 만들고 `sidebars.ts`에 ID를 등록하세요. 기존 엔진 문서는 루트 `docs/`에서 수정합니다. 동기화된 `website/docs/engine/`은 직접 수정하지 않습니다.

## 컴포넌트 재사용

`src/components/`에 TypeScript 컴포넌트를 만들고 MDX에서 import하세요. 브라우저 API가 필요한 코드는 `BrowserOnly` 또는 effect 내부에서 실행해 정적 빌드와 호환되게 합니다.

```tsx
import Playground from '@site/src/components/Playground';
// MDX 본문에서 <Playground /> 사용
```

## 버전 관리

릴리스가 확정되면 `npm run docs:version -- 0.1.0`으로 스냅샷을 만드세요. `versioned_docs/`, `versioned_sidebars/`, `versions.json`을 함께 커밋합니다. 현재 포털은 Development만 제공하며, 가상의 릴리스 문서를 만들지 않습니다.

## 언어별 코드 탭

Docusaurus의 `Tabs`와 `TabItem`을 사용합니다. Getting Started에서 운영체제별 탭의 실제 예시를 볼 수 있습니다. C API를 JavaScript API처럼 번역해 설명하지 마세요.
