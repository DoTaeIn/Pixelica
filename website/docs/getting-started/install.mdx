# Getting Started

CMake 3.21 이상과 C11 컴파일러를 준비하세요. 다음은 저장소 README의 헤드리스 빌드 흐름입니다.

<Tabs groupId="platform">
<TabItem value="unix" label="macOS / Linux">

```bash
cmake -S . -B build-docs-demo -DCMAKE_BUILD_TYPE=Debug -DPIXELICA_PLATFORM=HEADLESS
cmake --build build-docs-demo
ctest --test-dir build-docs-demo --output-on-failure
./build-docs-demo/hello_cube --frames 10
```

</TabItem>
<TabItem value="windows" label="Windows">

```powershell
cmake -S . -B build-docs-demo -DPIXELICA_PLATFORM=HEADLESS
cmake --build build-docs-demo --config Debug
ctest --test-dir build-docs-demo -C Debug --output-on-failure
.\build-docs-demo\Debug\hello_cube.exe --frames 10
```

</TabItem>
</Tabs>

## 실행 결과

HEADLESS에서는 창을 열지 않고 마지막 프레임의 해시를 출력합니다. SDL3 창 실행과 선택 모듈은 [저장소 README](https://github.com/DoTaeIn/Pixelica#readme)를 확인하세요.

## SDL3 창으로 실행

설치된 SDL3가 있다면 `PIXELICA_FETCH_SDL3`를 생략하고 필요에 따라 `CMAKE_PREFIX_PATH`를 지정하세요. 아래 명령의 다운로드 옵션은 SDL3를 소스에서 받아 빌드합니다.

```bash
cmake -S . -B build-docs-sdl -DCMAKE_BUILD_TYPE=Debug -DPIXELICA_PLATFORM=SDL3 -DPIXELICA_FETCH_SDL3=ON
cmake --build build-docs-sdl --target hello_lighting --config Debug
```

macOS/Linux에서는 `./build-docs-sdl/hello_lighting`, Visual Studio에서는 `.\build-docs-sdl\Debug\hello_lighting.exe`를 실행합니다. macOS의 온라인 모듈은 지원 경로에 포함되지 않습니다.

## 선택 기능 켜기

| 기능 | CMake 옵션 | 기본값 |
| --- | --- | --- |
| 본 스키닝 | `PIXELICA_BUILD_SKELETON=ON` | OFF |
| CPU 후처리 효과 | `PIXELICA_BUILD_SHADERS=ON` | OFF |
| 수면·부력 | `PIXELICA_BUILD_WATER=ON` | OFF |

수명주기·저장소·클립은 공통 라이브러리에 포함됩니다. 노멀 조명과 빛 패치의 3D 출력은 3D 코어를 사용합니다. 물 기능은 [별도 애드온 설치](../guides/water.mdx)도 가능합니다. 전체 옵션과 SDK 소비자 설정은 [SDK 가이드](../engine/sdk.md)를 확인하세요.
