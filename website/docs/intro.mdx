# 작은 픽셀에서 시작하는 가능성.

GPU 없이, C11로. Pixelica의 렌더링 구조를 이해하고 첫 프레임을 만들어 보세요.

:::info 개발 중인 문서 포털
사이트 브랜드는 Pixellica이며, 현재 저장소와 C API 식별자는 **Pixelica**입니다. 이 포털은 예시 문서와 데모를 포함하는 개발 버전입니다. 실제 API 계약은 저장소의 공개 헤더가 기준입니다.

## 어디서 시작할까요?

**처음이라면** Getting Started에서 CMake로 엔진을 빌드하세요. **구현을 살펴보려면** Architecture와 API Reference를 확인하세요. 기존 기술 문서는 왼쪽의 원문 섹션에서 찾을 수 있습니다.

## 문서의 기준

엔진은 RGB565 프레임버퍼에 그리는 C11 소프트웨어 렌더러입니다. 웹 데모는 렌더링 개념을 실험하는 독립적인 Canvas 예제이며, C 엔진의 웹 바인딩이나 공식 JavaScript SDK는 아닙니다.

## 현재 사용할 수 있는 기능

2D·2.5D·3D 렌더링에 게임 수명주기, 체크포인트 저장, 본별 애니메이션 클립·전환·이벤트를 연결할 수 있습니다. 3D 노멀 조명, 화면 가산 합성, 빛 패치·접촉 그림자·선택적 블룸으로 픽셀 스타일을 다듬습니다.

수면·부력은 기본 SDK와 분리된 선택 모듈입니다. [게임 기능 가이드](./guides/game-features.mdx)에서 기능별 연결 방법과 제한을, [물 애드온](./guides/water.mdx)에서 빌드·배포 방법을 확인하세요.

현재 문서는 Development 작업 트리를 기준으로 합니다. macOS ARM64의 기본 엔진·SDL3 창과 물 모듈을 로컬 검증했으며, 온라인 모듈은 Windows/Linux 경로를 사용합니다. ESP32-P4 실보드 검증은 아직 하지 않았습니다.
